Branch `feat/WP-21-web-foundation`. Milestone A-M5. Owns `web/` (app
shell, BFF routes, i18n, generated API types, the inspector map page),
the CI job `web`, and the web Docker image. Depends on WP-13

## What to build

- Next.js App Router, TypeScript strict, Tailwind + shadcn/ui through
  `uspace-ui`'s theme; `pnpm` with a lockfile; `openapi-typescript` from
  `../api/openapi.yaml` into `web/src/api/` (committed, verified in CI);
  a WebSocket client typed from `schemas/picture/*` via
  `json-schema-to-typescript` (committed, verified).
- BFF under `/_bff/*`: login and MFA forms post to `api` server-side,
  the session JWT is set as an `HttpOnly`, `Secure`, `SameSite=Strict`
  cookie, forwarded as a bearer by a single fetch wrapper; CSRF token
  on every mutating form; logout clears; no token in browser code; no
  database, NATS, geometry or JWT library in `web/` (ESLint
  `no-restricted-imports` for `turf`, `h3`, `proj4`, `jose`, `pg`,
  `nats`; a CI grep as backstop).
- i18n: `ka` and `en` message catalogues from day one, every string
  through the catalogue (a lint rule flags string literals in JSX
  outside the catalogue); branding (name, logo, contact) from
  environment at build time.
- Pages in this WP: login/MFA, the app shell with navigation per role,
  and the **inspector map**: MapLibre from `uspace-ui` with the zone and
  track symbology, viewport-driven `/v1/picture/ws` subscription,
  tracks with trust class, identification status (with "as broadcast
  and unverified" for every broadcast and provider track), age, source
  state panel (enabled / disabled by whom / stale / lagging / never
  heard), active violations panel replayed on connect, the status
  frame's degraded inputs shown as a banner (`bus unavailable since T`,
  `projection stale`, `cis stale`, `dp unavailable`), `dropped_frames`
  visible.
- Accessibility baseline (keyboard navigation, contrast from the kit),
  Georgian font rendering checked in a Playwright screenshot test.
- Dockerfile for `web` (built in CI; `next build` never on the server),
  `output: standalone`.

## Tests

- `tsc --noEmit`, ESLint strict with the restricted-import rules (a
  test fixture that imports `turf` must fail lint, E-01), generated
  types up to date.
- Playwright smoke against a stub API and a stub picture WS: login →
  map → tracks appear → a `bus unavailable` status frame shows the
  banner and the tracks stay with age (E-02); the Georgian catalogue
  renders.
