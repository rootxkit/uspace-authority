# WP-22: web: registry, zones, U-space and certificates

Branch `feat/WP-22-web-registry-zones-certs`. Milestone A-M5. Owns the
`web/` pages for the registry, zone and U-space authoring, publications
and certificates. Depends on WP-21 (and the APIs of WP-3, WP-5, WP-6,
WP-16, WP-20). Consumers: A-M1's "authored in the console" clause,
A-M5.

## Read first

1. `docs/PLAN.md` §5 registry, zone, U-space, certificate rows.
2. Spec `02 §3` authority groups; `03 §1`; `09 §1.6` (ED-318 fields the
   editor must present by their standard names).
3. The runbooks of WP-3 (registry), WP-5 (zones: authoring flow, ED-269
   import rules, the UNVERIFIED notes to show), WP-6 (publication
   states), WP-16 (certificates), WP-20 (import dry run).
4. LESSONS Z-05 (WGS84 reference flagged as this project's extension),
   Z-11 (a circle is centre and radius; the editor draws it but submits
   centre and radius), E-02.

## What to build

- Registry: operator, UAS and pilot lists with search by number and
  serial; detail pages; create and edit forms with the Art. 14(2)
  fields; status transitions with a mandatory reason; PII fields shown
  only to roles that may see them and every view carries a `purpose`
  selector that is sent with the request; import page with the dry-run
  report by row and field; applications queue (flag).
- Zones: list and map of versions in force and drafts; an editor on the
  `uspace-ui` map (polygon and circle tools; the circle submits centre
  and radius) with a form for every ED-318 property by its standard
  name, applicability schedules with daylight events, vertical limits
  with reference and unit (WGS84 flagged), zone authority entries;
  version history and diff; approve and publish actions with the
  publication state and "not yet published for N s" from WP-6; ED-318
  and ED-269 import with the problem list by path; export at `at`.
- U-space airspace: the designation form with the Art. 3(4) block,
  services required, adjacency, controlled-airspace flag, designation
  and AIP references; publish.
- Certificates: list, issue, suspend, limit, revoke with reasons;
  operating-status timeline; the public register preview; the USSP list
  publication state.
- Every destructive or publishing action confirms with the exact
  effect ("this publishes 1,243 zones to the CISP as version N").

## Tests

- Playwright against the stub API: author a zone (polygon and circle),
  see the problem list on an invalid import, publish and see the state;
  the circle request body carries centre and radius; a `viewer` sees no
  edit controls (E-01 beside an `inspector` who does).
